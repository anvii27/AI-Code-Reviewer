# AI Code Reviewer

An AI-powered code review application that analyzes source code and provides intelligent feedback, suggestions, and improvements using Large Language Models (LLMs).

Built to help developers identify:
- Bugs and logical issues
- Code smells
- Optimization opportunities
- Best practice violations
- Readability improvements

The project aims to simulate an automated senior developer review process using AI.

---

## Features

- AI-generated code reviews
- Detects potential bugs and inefficiencies
- Suggests code improvements
- Supports multiple programming languages
- Clean and responsive UI
- Real-time review generation
- Easy integration with developer workflows

---

---

## How It Works

1. User pastes code into the editor
2. Backend sends the code to the AI model
3. AI analyzes the code
4. Review feedback is generated and displayed to the user

---

## Installation

Clone the repository:

```bash
git clone https://github.com/anvii27/AI-Code-Reviewer.git
```

Move into the project directory:

```bash
cd AI-Code-Reviewer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Environment Variables

Create a `.env` file in the root directory and add:

```env
API_KEY=your_api_key
```
